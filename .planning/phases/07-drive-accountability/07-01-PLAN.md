# Plan 07-01: A User-Minted Goal Surfaces In The Appraisal Block

## Objective

This is the foundation tracer bullet for the drive layer: a user mints a goal, it persists in the
existing anansi SQLite surface, it reaches the appraisal model as untrusted reference state, and it
comes back out as one observational `- drive note:` line in the rendered `[anansi appraisal]` block —
in the same turn, through the existing `pre_llm_call` path, with no new hook and no second DB. It
also lands the SEPARATE drive kill switch (DRIVE-06 partial) so the whole drive layer can be turned
off independently of appraisal: drive off ⇒ goal fields vanish, appraisal otherwise unchanged. This
plan deliberately ships only a BASIC goal-aware field (`relates_to_goal`); the velocity-aware
fields (`stalled_days`, momentum) come in 07-02 and the first-person voice + never-omit in 07-03.
