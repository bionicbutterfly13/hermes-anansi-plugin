# Plan 07-02: A Stalled Goal Surfaces Louder

## Objective

Build the per-goal progress-velocity signal (DRIVE-02) that makes the drive layer accountable: a
goal with no recent activity surfaces with a louder `stalled N days` signal than one that is moving.
"Louder" means SALIENCE and ORDERING (surface earlier, render first) — never louder imperative
language, which SAFE-04 forbids and reactance research penalizes. Momentum is derived from GROUND
TRUTH (git reflog committer timestamps + project file mtimes) at appraisal-READ time, mirroring the
`_effective_weight` decay-at-read idiom — NOT behind debounced reflection, so a goal that stalled
this turn reads stalled this turn. The git/file signal uses stdlib `open()` (read mode) + `os.stat`
ONLY — `subprocess`/`os.system`/git libraries are anti-creep tripwires that brick the suite.

**Code facts (verified during planning):**
- `store.py:_effective_weight` (`:247-264`): the decay-at-read idiom — `datetime.fromisoformat`, naive→UTC coercion, `days_idle = max(0, (now - ts).total_seconds()/86400)`, try/except returns the safe value on any error, NEVER raises. The velocity helper MIRRORS this style exactly.
- `read_snapshot` (`:267-329`) is read-only, returns None on any error, never creates files — the right home for derived-at-read momentum (add momentum to each goal dict here, OR compute in a helper called from pre_llm_call; either way READ-TIME).
- Git ground truth, verified this session: `.git/HEAD` contains `ref: refs/heads/master`; `.git/logs/HEAD` reflog lines are `<old_sha> <new_sha> <name> <email> <committer_epoch> <tz>\tcommit: <msg>` — the committer epoch is the integer field immediately BEFORE the tz offset, before the `\t`. `.git/refs/heads/<branch>` holds the current tip sha. ALL of these are plain read-mode `open()` targets.
- `os.stat(path).st_mtime` gives a float epoch for any project file — already imported (`import os` in store.py).
- Discover the project root from `$HERMES_HOME`/cwd discovery, NEVER a literal path (standing rule). For a goal with a `domain` or path hint, mtime the relevant file/dir; otherwise fall back to the repo reflog recency. A goal with no resolvable ground truth ⇒ momentum 'unknown' (NOT an error).
- `appraisal.parse_signals` goal_signals + `build_context` goals slice + `render.render_block` `- drive note:` line all exist from 07-01 — this plan EXTENDS them with `stalled_days`/momentum, it does not recreate them.
- Anti-creep: `test_anticreep.FORBIDDEN_SUBSTRINGS` includes `"subprocess"`, `"os.system"`, `"eval("`, `"exec("`; `test_safe04_import_allowlist` forbids non-stdlib top-level imports outside `{agent, hermes_cli, hermes_constants, anansi}`; `test_safe04_only_write_open_is_the_debug_dump` asserts exactly ONE write-mode open AND that no open() line contains the substring `config`.

**Hard rules (non-negotiable):**
- The velocity/git/file signal uses stdlib `open(path)` / `open(path, "r")` (READ mode) + `os.stat` ONLY. NEVER `subprocess`, `os.system`, `eval(`, `exec(`, or any git library. NEVER a write-mode open. NEVER the substring `config` on an `open()` line.
- Velocity is computed at appraisal-READ time (in `read_snapshot` or a helper called from `pre_llm_call`), NEVER in `reflection.maybe_reflect`.
- The helper lives in `store.py` (it touches the filesystem/git, which is store.py's I/O remit) — do NOT add a new plugin module (`test_scan_targets_are_the_plugin_modules` hard-codes the six-module set). It must NOT import sqlite3 for anything outside the existing surface.
- Fail-open: the helper returns a benign default on ANY exception; no path raises into `pre_llm_call`.
- ZERO new pip deps. Paths via discovery, never literals. NEVER touch `~/.hermes/plugins/anansi`. Suite green at every commit.
- Test command: `cd /Volumes/Asylum/repos/hermes-anansi-plugin && ./scripts/test.sh`. Commit per task.
