# Plan 07-03: The Block Speaks In First-Person Want And Never Drops A Flagged Priority

## Objective

Two drive red lines land here. (1) DRIVE-04: the drive layer earns its voice — a NEW allowlisted
`- drive want:` line that renders the agent's owned want in the FIRST person ("I want X ready by
Friday"), implemented as a label allowance, NOT a loosening of the second-person directive scan. The
sanitizer still neutralizes/quotes "you should…" everywhere, and the existing negative controls that
prove the checker can fail are preserved and extended. (2) DRIVE-05: the never-omit invariant —
silent omission of a user-flagged priority is betrayal (Dr. Mani's top anti-value). A
`flagged_priority` goal is exempted from the `[:3]` slice AND the token-cap line-drop, rendered
first and outside the truncation pop range, and proven to survive adversarial crowding.

**Code facts (verified during planning):**
- `render.render_block` (`:125-209`): each category sliced `[:3]` (`:151,:160,:168`); the token cap at `:204-208` pops TRAILING whole lines while `len(block)//4 > _MAX_BLOCK_TOKENS (500)` and `len(lines) > 2`. To make a flagged line un-droppable it must be rendered FIRST (right after SENTINEL+FRAMING) AND held out of the pop range (e.g. pop only from a protected tail index, or rebuild the cap loop so flagged lines are never in the droppable slice).
- `render._sanitize_text` (`:86-109`): strips injection patterns, `_validate_safe_content`, whitespace-normalize, truncate, then quotes the WHOLE field if `_SECOND_PERSON_DIRECTIVE_RE` matches outside quoted spans (`:105-106`). `_SECOND_PERSON_DIRECTIVE_RE` (`:81-83`) matches `you (should|must|need to|have to|shall)`. The first-person carve-out must NOT touch this regex — a first-person "I want" line simply does not trigger the second-person pattern, so it passes through unquoted; ensure the drive-want phrasing is genuinely first-person (no embedded "you should").
- `conftest.ALLOWED_LABEL_PREFIXES` (`:46-53`) — the label allowlist (07-01 added `- drive note:`); add `- drive want:`. `conftest.DIRECTIVE_PATTERNS` (`:30-42`) re-asserts no `you (should|must)` survives after quoted spans are stripped — LEAVE IT UNTOUCHED (it governs second person, which we still reject).
- `conftest.assert_no_directive_language` (`:72-96`): every content line must start with an allowlisted label AND match no DIRECTIVE_PATTERNS after quoted spans removed. A `- drive want: I want X by Friday` line passes because "I want" is not a directive pattern; a `- drive want: you should ship` line would be quoted by `_sanitize_text` first (so it survives only as reported material), and if not quoted it would correctly FAIL the checker — that asymmetry is exactly the negative control to prove.
- `test_anticreep.test_safe03_helper_actually_catches_violations` (`:217-231`): the existing negative controls (fails on "you should migrate now" + on an unlabeled line). KEEP these; ADD the drive-specific symmetric control. `test_safe03_corpus_with_low_trust_snapshots` (`:194-207`): the "block not None + substring present under crowding" shape to mirror for the never-omit test.
- `flagged_priority` is an INTEGER column on the goals table (07-01); read_snapshot surfaces it per goal; momentum annotation rides along (07-02).
