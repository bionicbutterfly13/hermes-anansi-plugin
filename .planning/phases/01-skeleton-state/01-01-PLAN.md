# Plan 01-01: Loadable Inert Plugin Proven Against the Live Install

## Objective

Create the anansi plugin skeleton (`plugin.yaml` + `__init__.py` with `register(ctx)` and three fail-open no-op hooks), deploy it by symlink into the live install, and empirically prove the four Phase-0 validation behaviors: it loads as `kind: standalone`, its hooks dispatch across a real turn with zero output change, a raising hook is isolated by the dispatcher, and the gateway lane dispatches hooks the same way as the CLI lane. This is the foundation every later phase builds on — PLUG-01..04 plus SUMMARY.md Phase-0 items 1, 2, 4.

## Context

- `/Volumes/Asylum/repos/hermes-anansi-plugin/.planning/research/ARCHITECTURE.md` — exact hook signatures (Hook Contract section), dispatcher semantics (`hermes_cli/plugins.py:1574-1609`), anti-patterns
- `/Volumes/Asylum/repos/hermes-anansi-plugin/.planning/phases/01-skeleton-state/01-CONTEXT.md` — locked decisions
- Live precedents: `/Users/manisaintvictor/.hermes/plugins/icarus/plugin.yaml` (manifest shape) and `/Users/manisaintvictor/.hermes/plugins/icarus/hooks.py:107-180,573` (working hook signatures, fail-open style)

Non-negotiable constraints from CONTEXT.md and research:

1. **Manifest landmine:** the loader string-scans the first 8192 bytes of `__init__.py` (`hermes_cli/plugins.py:1344-1373`) and coerces kind if it sees the strings `MemoryProvider` or `register_memory_provider`. Declare `kind: standalone` explicitly in plugin.yaml AND never let those strings appear anywhere in `__init__.py` — not even in comments or docstrings.
2. **Dispatcher kwarg landmine:** `invoke_hook` injects extra kwargs (e.g. `telemetry_schema_version`). Every hook MUST accept `**kwargs` or it raises `TypeError` on every call.
3. **Zero import-time side effects:** no DB open, no config read, no `sys.path` mutation, no host imports at module top level. Only stdlib `logging`/`functools` imports are allowed at top. Everything else is lazy inside `register(ctx)`/hook bodies.
4. **Fail-open guard from day one:** every hook body wrapped (decorator) in try/except → log warning → return `None`. This is Phase-1 scaffolding, not a Phase-3 retrofit.
5. **Paths never literal in code:** in shell commands use `HERMES_HOME="${HERMES_HOME:-$HOME/.hermes}"`. (On this machine it resolves to `/Users/manisaintvictor/.hermes`.)
6. Hermes CLI and test python: `/Users/manisaintvictor/.hermes/hermes-agent/venv/bin/python`. The `hermes` command is on PATH (verify with `which hermes`; if not, use the venv's bin).
7. Your shell cwd resets between bash calls — use absolute paths in every command, or `cd <abs> && ...` compounds.
