1. **Location:** `$HERMES_HOME/anansi/state.db`, resolved via the host's `get_hermes_home()` (lazy import inside a function from `hermes_constants`; fall back to `os.environ.get("HERMES_HOME", "~/.hermes")` expanded, if the import fails). NEVER a literal path in code (standing rule).
2. **Explicit tables:** `affect_summary`, `concerns`, `contradictions`, `trust_scores`, `turn_log`, `meta` (key-value rows; holds `schema_version`). Caps/decay columns (`expires_at`, `decayed_weight`) built into the schema NOW even though only Phase 3 writes them.
3. **PRAGMAs:** `journal_mode=WAL` (set at DB creation — persistent), `synchronous=NORMAL` and `busy_timeout=5000` on every write connection. Hot-path reads open `file:<path>?mode=ro` URI connections.
4. **Single write funnel:** ALL writes go through `apply_deltas()` in one transaction. Phase 3 reflection inherits this.
5. **Disposable-state doctrine:** ANY structural problem (corruption, schema_version mismatch, missing table, failed open) → quarantine (rename `state.db` → `state.db.quarantined-<UTC timestamp>`, move `-wal`/`-shm` sidecars too) + recreate fresh. No migration framework. Never raise into the turn.
6. **Seed caps:** concerns ≤ 20, contradictions ≤ 50, turn_log ≤ 500 rows (module constants; tune later with telemetry).
7. **Hook wiring:** in Phase 1 only `on_session_start` touches the store (availability check, silent on failure). `pre_llm_call`/`on_session_end` stay pure no-ops.
8. Tests run with `/Users/manisaintvictor/.hermes/hermes-agent/venv/bin/python -m pytest`. Tests must NEVER touch the real `$HERMES_HOME` — every store function accepts an optional `db_path` parameter and tests pass `tmp_path` paths.
9. Shell cwd resets between bash calls — use absolute paths or `cd <abs> && ...` compounds.

```python
    # create parent dir + DB + schema if absent; verify structure if present.

def read_snapshot(db_path: Path | None = None) -> dict | None:
    # hot-path read. sqlite3.connect(f"file:{db_path}?mode=ro", uri=True).
    # Returns {"schema_version": int, "affect_summary": dict|None, "concerns": [dict,...],
    #          "contradictions": [dict,...], "trust_scores": {key: value,...},
    #          "turn_log_count": int} — rows as plain dicts (cursor.description keys).
    # Returns None on ANY error (absent file, locked, corrupt, missing table). NEVER raises,
    # NEVER creates files.

def apply_deltas(deltas: dict, db_path: Path | None = None, busy_timeout_ms: int = 5000) -> bool:
    # THE single write entry point. Opens rw connection with PRAGMA synchronous=NORMAL and
    # busy_timeout=busy_timeout_ms; one transaction (with conn: / BEGIN...COMMIT) applying:
    #   "affect_summary": dict -> upsert the single row id=1 (summary, valence, arousal, intensity)
    #   "concerns_add": [dict,...] -> insert (text, weight, status='open', timestamps)
    #   "concerns_resolve": [id,...] -> set status='resolved', updated_at
    #   "contradictions_add": [dict,...] -> insert (kind, description, evidence)
    #   "trust_scores": {key: float,...} -> upsert
    #   "turn_log_add": [dict,...] -> insert (session_id, turn_id, user_excerpt, appraisal_json)
    # Unknown keys ignored with a debug log. After inserts, enforce CAPS inside the SAME
    # transaction: DELETE oldest rows (lowest id) beyond each cap. Timestamps = UTC ISO-8601.
    # Returns True on commit, False on ANY error (rollback implied). NEVER raises.
```
