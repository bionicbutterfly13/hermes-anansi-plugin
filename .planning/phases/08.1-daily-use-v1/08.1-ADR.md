- D-07 (Q7): v1 exit gate, answer "a", which authorizes the live run: `scripts/live_drive_smoke.py` exit 0 on chief-of-staff recorded in the live-smoke record; 7 days of telemetry; a day-7 review of 20 sampled blocks with `ANANSI_DEBUG_DUMP` on, each labeled useful / neutral / misleading by Dr. Mani.

- D-09 (Q9): Tracking, answer "yes" to A with reorder: GSD Phase 08.1 with six plans in this order: 01 lineage cleanup; 02 install + first live smoke on the main model (latency baseline); 03 turn marker + block-size telemetry; 04 `/goal` command + CLI; 05 aux-task routing to gpt-6-sol; 06 full kill switch.

## Risks

- gpt-6-sol acceptance by the account is unverified: the picker lists it via `_FORWARD_COMPAT_TEMPLATE_MODELS` (codex_models.py:43) even when live discovery lacks it. Plan 02/05 live runs verify it.
- Anansi adds up to the 8.0s appraisal deadline to chief-of-staff turns; a timeout silently drops the block (fail-open).
- Multimodal turns drop the block (`compose_user_api_content` returns None for non-str content).
- Protected flagged priorities can exceed the block's soft size target and are replayed every turn.
- Closing PR #2 and deleting its branch are outward-facing; they were authorized in D-02.
- This repository's AGENTS.md/CLAUDE.md says "Commit only when explicitly requested"; commits and `--no-ff` merges for 08.1 plans are authorized by D-02 and D-09.

## Success Criteria

- `./scripts/test.sh` fully green after each plan (no weakened assertions; the 260912-cqc worktree failure is fixed by the `_repo_root()` repair, not waived).
- `scripts/live_drive_smoke.py` exits 0 on chief-of-staff with the result recorded (plan 02 records the first run and its latency baseline, whatever the outcome).
- Seven days of telemetry: p50 <= 6s; timeouts <= 10% of appraised turns; parse_fail + llm_error <= 5%; median block size reported.
- Day-7 review of 20 sampled blocks. Decision rule: >= 50% useful and 0 misleading means proceed to Phase 9; < 25% useful means freeze; in between, the next increment is appraisal-prompt quality, not new layers.
- Constitution Principles I-VII hold for every plan (fail-open, no autonomy, never-omit, single SQLite surface, zero new dependencies and paths from config, inspectable drive, minimal change).
