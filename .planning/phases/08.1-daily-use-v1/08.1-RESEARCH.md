## Summary

The phase is mostly integration against host surfaces that already exist in hermes-agent 0.21.4, plus four
small plugin changes. The host facts check out with one hard exception: **`/goal` is a built-in Hermes
command** (`hermes_cli/commands.py:117`, "Set a standing goal Hermes works on across turns until achieved"),
and `register_command` silently skips any name that resolves to a built-in (`hermes_cli/plugins.py:670-675`).
D-04 as written cannot ship; the planner needs Dr. Mani's choice of name before Plan 04. The recommendation is
`/anansi goals <sub>`, which mirrors the CLI grammar `hermes anansi goals <sub>` exactly and lets one parser
serve both.

The other findings that change plan content: (1) any exception inside `register()` makes the host dispose
**every** registration, hooks included (`hermes_cli/plugins_loader.py:484-495`), and existing tests call
`register()` with a `SimpleNamespace` that has only `register_hook`, so every new registration must be
`getattr`-probed and individually guarded. (2) The 260912-cqc worktree currently passes 213/213, not 212/1,
because the never-omit test reads the ambient checkout's git reflog and main's reflog is fresh today; the
failure is time-dependent and will return 2 days after the last checkout activity unless that test is made
hermetic. (3) A rejected `gpt-6-sol` does not necessarily surface as an error: the host auxiliary client
treats "model incompatible with route" and "request timed out" as capacity errors that may fall back to
another provider (`agent/auxiliary_client.py:7323-7330`, `7604-7625`), so Plan 05 must verify the actual
model from the telemetry `model` column. (4) Telemetry is capped at 2000 rows and each turn writes at least
two rows, so a busy week can evict day-1 evidence before the day-7 review.

**Primary recommendation:** Execute the six plans in D-09 order, each on its own worktree branch; guard every
new `ctx.register_*` call; add the turn marker in the header and put "applies to this message only" at the
start of the existing framing line (no index churn in never-omit tests); add `telemetry.block_tokens` through
a stepwise additive migration (v5 to v6); resolve the `/goal` name collision with Dr. Mani before Plan 04.

## Common Pitfalls

### Pitfall 1: `/goal` is a built-in Hermes command
**What goes wrong:** `ctx.register_command("goal", ...)` logs a warning and returns None; `/goal` keeps invoking Hermes's own standing-goal loop.
**Why it happens:** plugins.py:670-675 rejects names resolved by `hermes_cli.commands.resolve_command`; commands.py:117 defines `goal`.
**How to avoid:** get Dr. Mani's decision on the name before Plan 04 (recommend `/anansi goals ...`); add a test asserting the chosen name does not resolve to a built-in using the host's `resolve_command`.
**Warning signs:** debug log "conflicts with a built-in command. Skipping."; `/goal list` answers with Hermes goal output.

### Pitfall 2: One failing registration unloads the whole plugin
**What goes wrong:** Hooks disappear silently; anansi stops appraising.
**Why it happens:** plugins_loader.py:484-495 disposes all of the plugin's registrations on any exception from `register()`.
**How to avoid:** `getattr` probe plus per-call `try/except Exception` for `register_command`, `register_cli_command`, `register_auxiliary_task`; keep the four `register_hook` calls first and unguarded as today (a failure there is a real load failure).
**Warning signs:** "Failed to load plugin 'anansi'" in logs; no telemetry rows after a turn.

### Pitfall 3: `_repo_root` fix alone leaves momentum broken
**What goes wrong:** `_repo_root` returns the worktree root but `_last_commit_epoch` returns None, so momentum falls back to `updated_at`.
**How to avoid:** route both through one `_git_dir()`; test a tmp linked-worktree fixture with absolute and relative `gitdir:`, a malformed `.git` file, and a `.git` directory control.

### Pitfall 4: Time-dependent never-omit test
**What goes wrong:** The gate fails 2+ days after the last checkout activity, on main or in any worktree.
**How to avoid:** pin `_repo_root` in test_drive_neveromit.py:387 as described in Plan 01; do not edit the assertion.

### Pitfall 5: Marker changes break byte-identity or index assertions
**What goes wrong:** Drive-off vs no-goals byte identity (Constitution VI) or `lines[2]` assertions fail.
**How to avoid:** compute the marker from inputs identical in both runs; keep the protected prefix at `[header, framing, flagged wants...]`; `floor = max(protected_count, 2)` (render.py:605) stays correct because header and framing are still two lines.

### Pitfall 6: Schema bump quarantines live state
**What goes wrong:** v5 DB fails `_verify_structure` at v6 and is quarantined, erasing baseline telemetry and goals.
**How to avoid:** stepwise additive upgrade; tests for v5→v6 and v4→v6 preserving rows; update `assert store.SCHEMA_VERSION == 5` at test_reflection_store.py:114 (legitimate behavior change, record why).

### Pitfall 7: Telemetry cap evicts the 7-day evidence
**What goes wrong:** `"telemetry": 2000` (store.py:43) with at least two rows per turn (`pre_llm_call` row + `reflect_*` row from `on_session_end`, reflection.py:756-768) covers roughly 1000 turns or fewer.
**How to avoid:** see Open Question 3 (raise the cap in Plan 03 or export a daily summary).

### Pitfall 8: Silent goal eviction at the cap
**What goes wrong:** `_enforce_goal_cap` deletes the oldest non-flagged goals beyond 50 inside every `apply_deltas` (store.py:691-708, `"goals": 50`); the 51st `add` silently erases one.
**How to avoid:** the handler counts non-flagged goals before and after and reports any eviction to Dr. Mani (anti-erasure, Principle III spirit).

### Pitfall 9: A rejected or slow `gpt-6-sol` masquerades as success
**What goes wrong:** "model incompatible with route" and "request timed out" are capacity reasons that may fall back to another provider (auxiliary_client.py:7323-7330, 7604-7625); the call can succeed on a different model, or overrun the 8s deadline and hold the single worker, producing `skipped:worker_busy` on following turns.
**How to avoid:** Plan 05 verification checks telemetry `model` on `ok` rows; `appraisal.run_appraisal` records `getattr(result, "model", "")`, which `PluginLlm._finish` fills from `response.model` (plugin_llm.py:388-400, 531).
**Warning signs:** `model` shows `gpt-5.6-terra` or another id; rising `skipped:worker_busy` count.

### Pitfall 10: The symlink makes branch switches live
**What goes wrong:** checking out a feature branch in the main checkout changes chief-of-staff's plugin code on next process start.
**How to avoid:** all plan work in sibling worktrees; the main checkout stays on `main`.

### Pitfall 11: `live_drive_smoke.py` probes the wrong network host
**What goes wrong:** `_network_up(host="api.anthropic.com", ...)` (scripts/live_drive_smoke.py:44) gates a codex-routed run; an Anthropic outage yields a false INCONCLUSIVE, and codex outages are not detected by the probe.
**How to avoid:** either drop the probe or make it non-authoritative; keep exit semantics 0/1/2. Also add an optional `--task anansi_appraisal` so Plan 05 exercises the aux route (the script calls `run_appraisal` directly and never runs `register()` in its own module instance).

### Pitfall 12: Old replayed blocks still count toward context
**What goes wrong:** each rendered block (~500-token soft cap; flagged wants may exceed it, render.py:597-604) stays in history until compaction.
**How to avoid:** nothing in this phase beyond the marker (patching replay is out of scope); report median `block_tokens` in the day-7 review.

### Linked-worktree git dir (Plan 01)
```python
def _git_dir(repo_root):
    """`.git` dir, or the `gitdir:` target of a linked-worktree `.git` FILE. Never raises."""
    try:
        dot_git = Path(repo_root) / ".git"
        if dot_git.is_dir():
            return dot_git
        if dot_git.is_file():
            with open(dot_git, "r", encoding="utf-8") as fh:
                first = fh.readline().strip()
            if first.startswith("gitdir:"):
                target = Path(first.split(":", 1)[1].strip())
                if not target.is_absolute():
                    target = Path(repo_root) / target
                target = target.resolve()
                if target.is_dir():
                    return target
        return None
    except Exception:
        return None
```
