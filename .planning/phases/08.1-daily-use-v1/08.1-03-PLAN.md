<objective>
Mark every appraisal block with its turn and scope, and record each block's size in telemetry (D-03).

Purpose: since host commit 7b3dcee928 every injected block is replayed on every later turn, so the model sees a growing stack of unmarked blocks. A turn marker plus an "applies to this message only" line keeps each block scoped without patching the host; `block_tokens` lets the day-7 review report the median block size (D-07).
Output: header `[anansi appraisal] turn N`, a framing line that starts with the scope phrase, schema v6 `telemetry.block_tokens` with an additive upgrade, and window-capable `telemetry_summary`.
</objective>
