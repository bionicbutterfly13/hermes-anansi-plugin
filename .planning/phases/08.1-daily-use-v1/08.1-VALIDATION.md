## Sampling Rate

- **After every task commit:** Run the targeted file(s) for that task (map below)
- **After every plan wave:** Run the full suite in the plan worktree, then on `main` after the `--no-ff` merge
- **Before `/gsd-verify-work`:** Full suite must be green; live smoke recorded
- **Max feedback latency:** 30 seconds
