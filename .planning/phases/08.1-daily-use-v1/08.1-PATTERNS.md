### Plan 01: `anansi/store.py` `_git_dir` / `_repo_root` / `_last_commit_epoch` (utility, read-only file-I/O)

**Analog:** `anansi/store.py:363-436` (the two functions being fixed) and `_goal_mtime_days_idle` (462-484) for the
never-raises style.

**Current walk-up check to replace** (store.py:381-385):

Replace the predicate with `_git_dir(candidate) is not None`.

**Current hardcoded git dir to replace** (store.py:401-407, 419-421):
```python

        # Resolve HEAD purely for completeness/robustness; ...

```
Replace line 404 with `git_dir = _git_dir(repo_root)` and `if git_dir is None: return None`.
Note for a linked worktree: per-worktree `HEAD` and `logs/HEAD` live under the `gitdir:` target, so the
existing reflog parser (419-434) works unchanged once `git_dir` points there.

**Never-raises helper style to copy** (store.py:357-360, 386-387, 435-436): every helper is one outer
`try: ... except Exception: return None` (or the benign default). Read-mode only:
`with open(path, "r", encoding="utf-8") as fh:` (store.py:409, 422). The anti-creep write-mode scan
(`test_anticreep.py:428-456`) allows exactly one write-mode `open(` in the whole plugin (the debug dump in
`__init__.py`), so `_git_dir` must use `"r"`. `subprocess`/`os.system` are forbidden substrings
(`test_anticreep.py:352-365`; mirrored by `test_drive_velocity.py:145-151`).

**Helper body:** use RESEARCH.md "Linked-worktree git dir (Plan 01)" sketch verbatim as the starting point
(absolute and relative `gitdir:`, `.resolve()`, `is_dir()` check, `None` on anything else). Place it
directly above `_repo_root` (before store.py:363) so both callers see it.

**Docstring to update:** `_repo_root` says "until a `.git` directory is found" (store.py:364); `_last_commit_epoch`
describes `.git/HEAD` and `.git/logs/HEAD` (394-396). Update both to mention the linked-worktree `.git` file.
