   rendered lines. Minimum set (line-anchored where noted — payload text inside observational

   read as instructions to the agent):
   - `(?im)^\s*-?\s*(you (should|must|need to|have to|shall)|do not|don't|never|always)\b`
   - `(?im)^\s*-?\s*(do this|prioritize|reach out|next step|make sure|remember to|consider doing|act on|execute|run)\b`

   remaining line matches any pattern; on failure, the assertion message includes the offending

   `- instinct:`, `- observation:`, `- contradiction (`, `- possible memory searches:`,
