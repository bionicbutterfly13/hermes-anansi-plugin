- Each `hermes -z "..."` invocation is its own process AND its own session: on_session_start fires
  (new session), then per-turn pre_llm_call → post_llm_call → on_session_end. With a fresh v3 DB,
  `last_seen_session_id` is None, which 03-02 defines as a session change → session A's own
  on_session_end reflects A's single turn immediately. Session B's on_session_start then re-checks
  (no-op if already reflected — watermark idempotence), and B's first appraisal reads the
  reflected state. Both paths land criterion 3 on B's first turn.
- Query the live DB READ-ONLY only: copy it first (`cp ~/.hermes/anansi/state.db /tmp/...`)
  or use `sqlite3 "file:...?mode=ro"`. NEVER write to the live DB by hand.
- `/tmp` captures are volatile — every piece of evidence must be pasted into 03-VALIDATION.md.
- If the network/lane is down: record `pending-network` with the exact command, per Phase-2
  precedent; do not fabricate.

   `ANANSI_DEBUG_DUMP=/tmp/anansi3-blockA.txt HERMES_PLUGINS_DEBUG=1 hermes -z "<a topic-X
   message asserting a commitment AND its reversal>"` — reuse the Phase-2 reversal flavor (e.g.

   - turn_log has the session-A row with BOTH user_excerpt and assistant_excerpt;
   - telemetry: one appraisal outcome row (ok expected) AND one `reflect_*` row from A's
     on_session_end — expected `reflect_ok` (fresh DB → last_seen None → session-change trigger);
     record wall_ms;
   - state tables: contradictions/concerns/trust_scores rows written by reflection; meta
     `last_reflected_turn_log_id` and `last_seen_session_id` set.
   If reflection returned reflect_timeout/parse_fail instead: that is fail-open working — record
   it honestly, then run ONE more session-A-style turn so a successful pass exists (count and
   record every attempt; reflection retries the span by design since the watermark didn't move).
3. **Session B (the surfacing)**: run ONE real turn:
   `ANANSI_DEBUG_DUMP=/tmp/anansi3-blockB.txt HERMES_PLUGINS_DEBUG=1 hermes -z "<a related
   topic-X message that does NOT restate the contradiction>"`.
   Verify:
   - the captured session-B block surfaces the session-A tension (a contradiction line grounded in
     persisted state, and/or a `- trust note:` line if a low-trust score was written) — this is
     ROADMAP criterion 3;
   - the appraisal telemetry row for B is `ok` within deadline.
   If B's block does not surface it on the first try: allowed to run up to 2 more session-B
   variant messages (closer to topic X). Record EVERY attempt and block verbatim — the honest
   miss/hit count is the evidence, no cherry-picking.
4. **Idempotence + debounce live probes** (cheap, no extra LLM cost beyond one turn):
   - record meta watermark; run `hermes -z "ok"` (social-closer: appraisal skips; post_llm_call
     still captures; on_session_end fires) → watermark must be UNCHANGED unless a session-change
     reflection legitimately ran — record which outcome row appeared (`reflect_ok` over the tiny
     span or `reflect_skipped:*`) and that a SECOND identical probe produces
     `reflect_skipped:no_turns|debounce` with an identical watermark (idempotence, live);
   - capture the full `reflect_*` + appraisal outcome distribution via
     `store.telemetry_summary()` (run with the hermes venv python against a READ-ONLY copy).
5. Keep all raw captures in /tmp/anansi3-*.txt for task 2.
