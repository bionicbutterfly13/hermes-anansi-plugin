# Plan 03-02: Reflection — the Cross-Lag Carrier (Offline, Fake LLM)

## Objective

Build the reflection pass (R2: the second half of the appraisal input contract, not polish): per-turn
transcript capture via `post_llm_call`, a debounced + idempotent LLM consolidation pass triggered from
`on_session_end`/`on_session_start`, bounded conservative deltas applied in ONE WAL transaction through
the `apply_deltas()` funnel, lazy concern decay at snapshot read, contradiction persistence/resurfacing
(REFL-04), and advisory trust hints in the rendered block (REFL-05). Everything proven offline against
fake LLMs; the live proof is Plan 03-03.

- `on_session_start` (conversation_loop.py:302-307) kwargs: `session_id, model, platform` only.
  "Fired once when a brand-new session is created (not on continuation)."
- `post_llm_call` IS in the host's `VALID_HOOKS` (hermes_cli/plugins.py:128); `register_hook`

- **Echo-chamber risk is structurally absent**: BOTH the memory block and our `[anansi appraisal]`
  context are injected at API-call time only — `messages` is never mutated
  (conversation_loop.py:610-627: "the original message in `messages` is never mutated, so nothing
  leaks into session persistence"). So `post_llm_call`'s `user_message`/`conversation_history` are

   gpt-5 family). Outcomes: `reflect_ok|reflect_timeout|reflect_parse_fail|reflect_llm_error`
   (trust fallback that succeeds → `reflect_ok`; the fallback distinction matters less here and
   keeps the outcome vocabulary small). NEVER raises.
7. `parse_reflection(doc) -> dict`: parse_signals-grade defensive coercion. EVERY delta clamped to
   [-MAX_DELTA, +MAX_DELTA]; new_concerns weight clamped [0,1] and list capped at
   MAX_NEW_CONCERNS; unknown contradiction kinds DROPPED; descriptions/evidence/texts truncated
   (500 chars); id lists coerced to ints; trust_adjustments capped at MAX_TRUST_ADJUSTMENTS,
   keys truncated to 100 chars.
8. `apply_reflection(parsed, *, span_end_id, db_path=None) -> bool`: compose ONE apply_deltas call
   (single WAL transaction — the idempotence core: watermark + deltas atomic):
   - `meta_set: {"last_reflected_turn_log_id": span_end_id}`;
   - `affect_summary`: current values (read first) ± clamped deltas; clamp results — valence to
     [-1, 1], arousal/intensity to [0, 1]; summary replaced only when non-empty;
   - `concerns_add` (new), `concerns_update` (current weight ± clamped delta, clamped [0,1]),
     `concerns_resolve` (ids that exist), `concerns_prune` (decay-prune: ids whose
     `weight * 0.5 ** (days_idle/7) < 0.1`, computed here from a raw read — this is where decayed
     rows actually die);
   - `contradictions_add` (new), `contradictions_resolve` (ids);
   - `trust_scores`: current ± clamped delta, clamped [0,1] (absent key starts at 0.5 baseline).
   Returns apply_deltas' bool. On False the watermark did NOT advance (same transaction) — the
   span is retried at the next trigger.
9. `maybe_reflect(*, llm, session_id, cfg=None, db_path=None) -> str` — the debounce gate +
   orchestration. NEVER raises; returns the outcome string and records it via record_telemetry
   (wall/model/tokens populated for real attempts). Order:
   a. cfg = config.get_cfg() if None; if not `enabled` or not `reflection_enabled` →
      `reflect_skipped:disabled`;
   b. if llm is None → `reflect_skipped:no_ctx`;

      is what makes the 03-03 single-turn live demo work);
   e. always update last_seen: apply_deltas({"meta_set": {"last_seen_session_id": session_id}})
      (cheap bookkeeping write through the funnel);
   f. if not turns → `reflect_skipped:no_turns`; if not session_changed and
      len(turns) < reflect_every_n_turns → `reflect_skipped:debounce`;
   g. digest = build_digest(turns, read_snapshot()); result = run_reflection(...); if outcome !=
      reflect_ok → record + return it (NO state mutation on any failure);
   h. parsed = parse_reflection(result.parsed); ok = apply_reflection(parsed,
      span_end_id=turns[-1]["id"]); if not ok → `reflect_skipped:db_locked` (no watermark
      advance); else record + return `reflect_ok`.
